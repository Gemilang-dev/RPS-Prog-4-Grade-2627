Case Background:
Last night, the containment atmosphere computer at BioGen Medical Labs was breached. A malicious actor injected assembly instructions into the HVAC micro-controller to manipulate oxygen and temperature levels in the hazardous virus storage unit. You are the Bio-Tech Security Forensic Investigator assigned to trace the breach and engineer a secure containment lock.

Part 1: Tracing the Digital Footprint (ADD, SUB, MOV)

Forensic RAM dumps retrieved an assembly sequence executed right before environmental alarms failed. Register AX stored the temperature sensor reading, and BX stored the pressure offset. Classify the registers and trace the execution step-by-step to reveal the hacker exfiltration channel.

MOV AX, 890
MOV BX, 340
SUB AX, BX
MOV CX, AX
ADD CX, 160
SUB AX, 80
MOV DX, CX
ADD DX, AX
Task 1: Memory Tracing & Architecture
  1. According to processor organization, classify the registers (AX, BX, CX, DX) used by the perpetrator based on their intended functions.
  2. Conduct a step-by-step memory trace. Write down the values of AX, BX, CX, and DX after each line of instruction executes. What is the final value stored in DX? (This value is the port number the perpetrator used to exfiltrate the data).

Part 2: The Logic Interrogation (CMP, JE, JNE, JMP)

Containment logs indicate the intruder reached the Bio-Hazard Gate. The gate checks authorization card numbers against Chief Scientist ID (ID = 2048). The intruder manipulated conditional branches to cause a system hang:

MOV EAX, [User_Input]
MOV EBX, 2048
CMP EAX, EBX
JNE Bio_Bypass
JE Containment_Secured

Bio_Bypass:
    MOV ECX, 1
    JMP Bio_Bypass  ; Endless loop traps processor to prevent vent closure

Containment_Secured:
    MOV ECX, 0

End_Program:
    ; Halt
Task 2: Branching Anomaly Analysis
  1. Identify and explain the severe logical flaw created by the perpetrator using the JE, JNE, and JMP instructions. How does this allow an unauthorized user to bypass the system and disable the alarm?
  2. Explain the concept of an "infinite loop" as seen in the Malicious_Bypass block. Why did the perpetrator intentionally trap the processor in this state instead of jumping to End_Program?

Part 3: Designing the New Security Protocol (Writing Assembly)

BioGen Administration commissioned you to author a brand-new electronic containment lock in assembly according to these requirements:

  • The system utilizes two registers: R1 (stores the correct PIN: 321) and R2 (stores the user input PIN).
  • You must compare R2 with R1.
  • If the PIN matches, the program must conditionally jump to a block named Seal_Containment.
  • If the PIN is incorrect, deduct 1 from register R3 (which tracks remaining attempts, starting at 3).
  • After deducting an attempt, the program must jump unconditionally to a block named Decontaminate_Zone.
Task 3: Assembly Implementation Write the complete inline Assembly code to model the security system described above. You must include comments (using the ; symbol) on every single line of your code to justify why that specific instruction was chosen based on the management's requirements.

Part 4: Recovery System Sabotage (Compilation Lifecycle)

When building the multi-module bio-safety control system, the build environment fails at the final linking phase with this message:

Fatal Error: Undefined reference to 'Seal_Containment' in module BioSafety.obj

Task 4: Compilation Diagnostics
  1. Management blames the Compiler for being corrupted by the hacker. Based on the compilation lifecycle, identify exactly which stage this error occurs in: is it the Compiler, the Parser, or the Linker?
  2. Provide a technical explanation for why this specific error appears in a multi-file project, and detail the steps you must take to resolve the missing reference.
